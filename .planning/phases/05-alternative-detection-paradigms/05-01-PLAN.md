Create RuleEngine class that loads and evaluates phishing rules:

```python
class RuleEngine:
    def __init__(self, rules_path: Path = None):
        """Load rules from YAML path or use default phishing_rules.yaml."""

    def evaluate(self, features: Dict[str, Any]) -> Dict:
        """Evaluate all rules against extracted URL features.

        Args:
            features: Dict from extract_url_features() with 30 numeric features

        Returns:
            Dict with:
                'score': float (0.0-1.0, capped)
                'prediction': 'phishing' or 'legitimate' (threshold 0.5)
                'confidence': float - distance from threshold
                'fired_rules': list of dicts with name, description, weight, matched_values
                'rule_count': int - number of rules that fired
                'max_possible_score': float - sum of all rule weights
        """
```

Implementation details:
1. `__init__`: Load YAML, validate with RuleSet pydantic model
2. `_evaluate_condition`: Handle each condition type:
   - `keyword_match`: Check if any keyword in condition.keywords appears in features[condition.feature] (case-insensitive). For URL features, may need to pass raw_url separately or check in url/domain string representations.
   - `feature_check`: Compare features[condition.feature] using operator (equals, greater_than, less_than, contains)
   - `domain_match`: Check if features[condition.feature] contains any of condition.domains
3. `_extract_matched_values`: Return list of specific matches for explanation
4. `evaluate`: Loop through rules, accumulate score, normalize to [0, 1] using min(total_score, 1.0)

**Important:** Rules evaluate against the features dict from extract_url_features(). For keyword matching, you may need to accept raw_url as optional parameter or check feature names that contain string data. For now, focus on feature_check rules which work with numeric features. Keyword matching can check if url/domain fields exist in features dict or accept them separately.

Handle edge cases:
- Missing feature: Return False for condition (don't crash)
- Empty features dict: Return score=0, prediction='legitimate'

Add logging for debugging rule evaluation.
