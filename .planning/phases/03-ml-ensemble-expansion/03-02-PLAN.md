  <action>
1. Create src/models/ensemble.py:

   Imports:
   - sklearn.ensemble: VotingClassifier, StackingClassifier
   - sklearn.linear_model: LogisticRegression (for stacking meta-model)
   - joblib for persistence
   - numpy for array operations

   Functions:

   a) create_voting_ensemble(estimators: list, voting: str = 'soft') -> VotingClassifier:
      - Takes list of (name, pipeline) tuples from train_ensemble
      - Returns VotingClassifier(estimators=estimators, voting=voting, n_jobs=-1)
      - NOTE: VotingClassifier.fit() will re-fit the estimators on the training data

   b) create_stacking_ensemble(estimators: list) -> StackingClassifier:
      - Same estimators list as voting
      - final_estimator=LogisticRegression(class_weight='balanced', max_iter=1000)
      - cv=5 (5-fold CV for meta-model training - prevents data leakage)
      - stack_method='auto' (use predict_proba if available)
      - passthrough=False (don't include raw features)
      - n_jobs=-1
      - Return StackingClassifier

   c) get_individual_predictions(voting_model: VotingClassifier, X) -> dict:
      - Access each classifier via voting_model.named_estimators_[name]
      - For each classifier: proba = clf.predict_proba(X)[0]
      - Return dict with per-classifier results:
        {
          'rf': {'phishing_probability': float, 'prediction': str, 'confidence': float},
          'svm': {...},
          ...
        }

   d) save_ensemble(model, path: Path, model_type: str):
      - Wrapper around joblib.dump with compress=3, protocol=5
      - Include metadata: model_type, created_at, sklearn_version

   e) load_ensemble(path: Path):
      - Wrapper around joblib.load
      - Return the model (VotingClassifier or StackingClassifier)

2. Update src/models/__init__.py to export ensemble functions

PITFALL: StackingClassifier with cv=5 handles data leakage automatically
