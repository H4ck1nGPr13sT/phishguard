1. **src/data/preprocessors/temporal_split.py**:

   ```python
   def temporal_split(
       df: pd.DataFrame,
       timestamp_col: str = 'timestamp',
       train_ratio: float = 0.7,
       val_ratio: float = 0.15,
       test_ratio: float = 0.15
   ) -> Tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame, Dict[str, Any]]:
   ```

   Implementation logic:
   a. Validate ratios sum to 1.0 (with tolerance for float precision)
   b. Separate data into with-timestamp and without-timestamp subsets
   c. Sort with-timestamp data by timestamp ascending
   d. Calculate split indices:
      - train_end = int(n_with_ts * train_ratio)
      - val_end = int(n_with_ts * (train_ratio + val_ratio))
   e. Split timestamped data:
      - train: [:train_end]
      - val: [train_end:val_end]
      - test: [val_end:]
   f. Append ALL without-timestamp samples to training set (conservative approach per CONTEXT.md)
   g. Generate split report:
      - with_timestamps: count of samples with valid timestamps
      - without_timestamps: count of samples without timestamps (added to train)
      - train_size, val_size, test_size: final counts
      - train_date_range: (min, max) timestamps in train
      - val_date_range: (min, max) timestamps in val
      - test_date_range: (min, max) timestamps in test
      - temporal_integrity: True if train_max < val_min < test_min
   h. Return (train_df, val_df, test_df, split_report)

2. Implement `verify_temporal_integrity(train_df, val_df, test_df, timestamp_col='timestamp') -> bool`:
   - Get max timestamp from train (ignoring NaT)
   - Get min timestamp from val
   - Get max timestamp from val
   - Get min timestamp from test
   - Assert: train_max < val_min AND val_max < test_min
   - Return True if valid, raise ValueError with details if not

3. Handle edge cases:
   - All samples without timestamps: all go to train, val/test are empty (log warning)
   - Very few samples: ensure at least 1 sample in each split if possible
   - Duplicate timestamps at split boundaries: keep together (don't split within same timestamp)

1. **src/data/preprocessors/balancer.py**:

   ```python
   def balance_training_data(
       X_train: pd.DataFrame,
       y_train: pd.Series,
       target_ratio: float = 0.5,
       random_state: int = None
   ) -> Tuple[pd.DataFrame, pd.Series, Dict[str, Any]]:
   ```

   Implementation logic:
   a. Import from settings if random_state not provided: `from src.config.settings import RANDOM_SEED`
   b. Record original class distribution: `original_counts = y_train.value_counts().to_dict()`
   c. Determine minority/majority classes
   d. Create imbalanced-learn Pipeline:
      ```python
      from imblearn.over_sampling import SMOTE
      from imblearn.under_sampling import RandomUnderSampler
      from imblearn.pipeline import Pipeline as ImbPipeline

      resampler = ImbPipeline([
          ('smote', SMOTE(sampling_strategy='auto', random_state=random_state, k_neighbors=5)),
          ('undersample', RandomUnderSampler(sampling_strategy=target_ratio, random_state=random_state))
      ])
      ```
   e. Fit and resample: `X_resampled, y_resampled = resampler.fit_resample(X_train, y_train)`
   f. Generate detailed balance report:
      - original_counts: {0: count, 1: count}
      - final_counts: {0: count, 1: count}
      - technique: 'SMOTE + RandomUnderSampler'
      - target_ratio: the ratio used
      - synthetic_samples_added: len(X_resampled) - len(X_train) after SMOTE (before undersample)
      - samples_removed: by undersampling
      - random_state: seed used
   g. Return (X_resampled as DataFrame, y_resampled as Series, balance_report)

2. Handle edge cases:
   - Already balanced data: skip resampling, return original with note in report
   - Very few minority samples (< k_neighbors for SMOTE): reduce k_neighbors or use simple oversampling
   - All one class: raise ValueError (cannot balance)

3. Add helper function `get_class_distribution(y: pd.Series) -> Dict[str, Any]`:
   - Returns: {class_label: count, 'majority': label, 'minority': label, 'imbalance_ratio': ratio}

4. CRITICAL: Document clearly that this function should ONLY be called on training data:
