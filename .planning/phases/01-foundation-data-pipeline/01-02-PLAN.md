   ```python
   import pandera as pa
   from pandera import Column, DataFrameSchema, Check
   import pandas as pd
   from typing import Tuple, Dict, Any
   ```

   Define `PhishingDataSchema` using Pandera DataFrameSchema with columns:
   - `url`: str, nullable=False, checks: non-empty (length >= 1), valid URL prefix (http:// or https://) OR empty string (for UCI feature-based data)
   - `label`: int, nullable=False, checks: value in [0, 1] (binary classification)
   - `content`: str, nullable=True (text content may be missing for URL-only datasets)
   - `timestamp`: datetime64[ns], nullable=True (some sources lack timestamps)
   - `source`: str, nullable=False, checks: value in ['phishtank', 'uci_ml', 'nazario']

   Schema settings:
   - `unique=['url']` only if url is non-empty (handle UCI separately)
   - `coerce=True` to attempt type conversion
   - `strict=False` to allow additional metadata columns

2. Implement `validate_dataset(df: pd.DataFrame) -> Tuple[pd.DataFrame, Dict[str, Any]]`:
   - Try schema validation with `lazy=True` to collect all errors
   - Generate validation report dict with:
     - `total_samples`: original count
     - `valid_samples`: count after validation
     - `rejected`: dict of {check_name: count} for failures
     - `statistics`: {null_timestamps, sources (value_counts), class_distribution (value_counts)}
   - On SchemaErrors: filter out invalid rows, log rejections, return valid subset
   - Return (validated_df, validation_report)

3. Handle encoding errors in string columns:
   - Add custom check for printable characters (optional warning, not rejection)
   - Replace unprintable chars with placeholder in cleanup step

Implement quality checks and multi-source merger per CONTEXT.md (strict validation, generate full validation report):

1. **src/data/validators/quality.py**:
   ```python
   def deduplicate_dataset(df: pd.DataFrame, method: str = 'exact') -> Tuple[pd.DataFrame, int]:
   ```
   - `method='exact'`: Drop duplicates on 'url' column, keep first occurrence
   - `method='fuzzy'`: Normalize URLs first (lowercase, strip trailing slash, remove www.), then deduplicate
   - Return (deduplicated_df, removed_count)
   - Log how many duplicates removed

   ```python
   def check_data_quality(df: pd.DataFrame) -> Dict[str, Any]:
   ```
   - Comprehensive quality report without modification:
     - empty_urls: count of empty/null URLs
     - invalid_labels: count of labels not in [0, 1]
     - missing_timestamps: count of null timestamps
     - duplicate_urls: count of duplicate URLs
     - encoding_issues: count of rows with non-UTF8 characters (best effort detection)
     - class_balance: ratio of label=1 to total
     - source_distribution: dict of source value counts

2. **src/data/preprocessors/merger.py**:
   ```python
   def merge_datasets(datasets: Dict[str, pd.DataFrame], validate: bool = True) -> Tuple[pd.DataFrame, Dict[str, Any]]:
   ```
   - Input: dict of {source_name: DataFrame} from downloaders
   - Standardize column names across sources (map to url, label, content, timestamp, source)
   - Handle UCI ML's feature-based format (no raw URL - set url='', keep features as additional columns)
   - Concatenate all DataFrames
   - If validate=True, run validate_dataset and deduplicate_dataset
   - Generate merge report:
     - samples_per_source: {source: count}
     - total_before_merge: sum of all sources
     - total_after_validation: count after validation
     - total_after_dedup: count after deduplication
     - validation_report: from validate_dataset
   - Return (merged_df, merge_report)

   Column mapping per source:
   - PhishTank: url (from 'url'), label=1 (all phishing), timestamp (from 'verified_at'), content=None
   - UCI ML: url='' (features only), label (from 'Result' mapped 0/1), timestamp=None, keep all feature columns
   - Nazario: url (extracted), label=1 (all phishing), timestamp (from Date header), content (email body)
