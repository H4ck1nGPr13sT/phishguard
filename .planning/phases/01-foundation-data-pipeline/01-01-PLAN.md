  <action>
Implement dataset downloaders per CONTEXT.md decisions (download from multiple sources, local cache fallback, log success/failure):

1. **src/data/downloaders/phishtank.py**:
   ```python
   def download_phishtank(api_key: str = None, cache_dir: Path = None, force_refresh: bool = False) -> pd.DataFrame:
   ```
   - Use PHISHTANK_API_KEY from settings if not provided
   - Download from PhishTank API (JSON format with bz2 compression)
   - Show progress bar via tqdm
   - Cache to `cache_dir/phishtank_latest.json`
   - On download failure, fall back to cached data if exists
   - Log success/failure with sample count
   - Return DataFrame with columns: url, label (1=phishing), timestamp (from verified_at), source='phishtank'
   - Handle empty/malformed API responses gracefully

2. **src/data/downloaders/uci_ml.py**:
   ```python
   def download_uci_phishing(cache_dir: Path = None, force_refresh: bool = False) -> pd.DataFrame:
   ```
   - Download UCI Phishing Websites dataset (ARFF format)
   - Parse ARFF using scipy.io.arff
   - Cache to `cache_dir/uci_phishing.csv`
   - Convert -1/1 labels to 0/1 (Result column)
   - Add columns: source='uci_ml', timestamp=None (dataset has no timestamps)
   - URL column: reconstruct from features or set to empty (UCI has features, not raw URLs)
   - Log success/failure

3. **src/data/downloaders/nazario.py**:
   ```python
   def parse_nazario_corpus(mbox_path: Path) -> pd.DataFrame:
   ```
   - Parse mbox file using Python mailbox module
   - Extract: url (first URL from body via regex), subject, from_addr, content (body text), timestamp (from Date header)
   - All samples have label=1 (Nazario is phishing-only corpus)
   - Add source='nazario'
   - Handle encoding errors gracefully (try utf-8, latin-1, ignore on failure)
   - Extract ALL URLs from body, create one row per unique URL per email
   - Log parsing progress and final count

4. **src/data/downloaders/__init__.py**:
   - Export all three functions
   - Add convenience function: `download_all_sources(config) -> dict` that calls all downloaders and returns {source: {status, samples, data}} dict per RESEARCH.md pattern

Note: UCI ML dataset has pre-extracted features, not raw URLs. This is intentional - it provides URL-derived features directly. For Phase 2, we'll need to handle both feature-based (UCI) and URL-based (PhishTank, Nazario) inputs.
  </action>
