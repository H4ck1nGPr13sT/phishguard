  <action>
Create feature selection module using GA:

**Binary representation:** Each individual is a binary array of length N (number of features). 1 = feature selected, 0 = feature excluded.

**setup_feature_selection_toolbox(X_train, y_train, min_features=5):**
- Create FitnessMax for F1 maximization
- Create Individual as list of 0/1 values (length = n_features)
- Register attribute generator: random.randint(0, 1)
- Register genetic operators:
  - evaluate: fitness function using selected features
  - mate: tools.cxTwoPoint (two-point crossover works well for binary)
  - mutate: tools.mutFlipBit with indpb=1/n_features
  - select: tools.selTournament with tournsize=3
- Constraint: enforce min_features (at least 5 features must be selected)

**evaluate_feature_subset(individual, X_train, y_train, classifier='rf'):**
- Extract features where individual[i] == 1
- If fewer than min_features, return (0.0,) fitness
- Train RF classifier (fast, robust) on selected features
- Evaluate with 5-fold CV F1-score
- Return (f1_mean,)

Note: Use RF as proxy classifier for speed. Selected features will be used by all classifiers.

**run_feature_selection(toolbox, population_size=30, n_generations=20):**
- Smaller population than hyperparameter optimization (binary space is simpler)
- Fewer generations (feature selection converges faster)
- Track and return: best_individual, selected_indices, logbook

**get_selected_features(individual, feature_names):**
- Convert binary individual to list of selected feature names
- Return dict: {'indices': [...], 'names': [...], 'n_selected': N}

**GA parameters for feature selection:**
- population_size: 30 (smaller than hyperparameter search)
- n_generations: 20 (binary representation converges faster)
- cxpb: 0.5 (lower crossover for binary)
- mutpb: 0.2
- min_features: 5 (minimum to prevent degenerate solutions)
  </action>
