<task type="auto">
  <name>Task 3: Create GA optimizer with DEAP toolbox</name>
  <files>src/optimization/ga_optimizer.py</files>
  <action>
Create GA optimizer module implementing:

**setup_toolbox(classifier_name, X_train, y_train):**
- Create FitnessMax and Individual types using DEAP creator
- Register attribute generators for each hyperparameter based on SEARCH_SPACES
- Handle int (random.randint), float (random.uniform with log scale option), categorical (random.choice)
- Register individual creation using tools.initCycle
- Register population using tools.initRepeat
- Register genetic operators:
  - evaluate: fitness function with closure over X_train, y_train
  - mate: tools.cxOnePoint (single-point crossover per GA-04)
  - mutate: tools.mutUniformInt for int params, custom for float/categorical
  - select: tools.selTournament with tournsize=3 (per research)
- Set mutation probability indpb=0.2 per gene

**run_ga_optimization(toolbox, population_size=50, n_generations=30, cxpb=0.7, mutpb=0.2):**
- Create initial population
- Initialize HallOfFame(maxsize=10) for elite preservation (prevents pitfall #5)
- Set up Statistics tracking (avg, std, min, max fitness)
- Run algorithms.eaSimple with stats and halloffame
- Return (best_individual, logbook, hall_of_fame)

**GA parameters per research:**
- population_size: 50 (default, adequate for 4-9 hyperparameters)
- n_generations: 30 (with early stopping consideration)
- cxpb: 0.7 (crossover probability)
- mutpb: 0.2 (mutation probability, higher than typical 0.1 to prevent premature convergence)
- tournsize: 3 (selection pressure balance)

Add logging at INFO level for generation progress.
