  <action>
Create module for GA-based ensemble weight optimization:

**Weight representation:** Individual is array of 7 floats (one per classifier), normalized to sum to 1.0.

**setup_weight_optimization_toolbox(classifiers, X_train, y_train):**
- Create FitnessMax for F1 maximization
- Create Individual as list of 7 float values [0.0, 1.0]
- Register attribute generator: random.uniform(0.0, 1.0)
- Weights will be normalized in fitness function
- Register genetic operators:
  - evaluate: weighted voting fitness
  - mate: tools.cxBlend(alpha=0.5) - blend crossover works well for continuous
  - mutate: tools.mutGaussian(mu=0, sigma=0.1, indpb=0.3)
  - select: tools.selTournament with tournsize=3

**normalize_weights(individual):**
- Ensure all weights >= 0.01 (minimum contribution)
- Normalize so sum = 1.0
- Return normalized weights

**evaluate_weighted_ensemble(individual, classifiers, X_train, y_train):**
- Load pre-trained optimized classifiers (from Plan 02)
- Get predictions from each classifier
- Apply normalized weights to soft voting
- weighted_proba = sum(weight_i * predict_proba_i for each classifier)
- Final prediction = argmax(weighted_proba)
- Evaluate with 5-fold CV F1-score
- Return (f1_mean,)

**run_weight_optimization(toolbox, population_size=30, n_generations=20):**
- Smaller search space than hyperparameter optimization
- Quick convergence expected
- Track: best_weights, final_fitness, logbook

**create_weighted_ensemble(weights, classifier_paths):**
- Load classifiers from paths
- Create VotingClassifier with specified weights
- Return fitted ensemble ready for prediction

**GA parameters for weight optimization:**
- population_size: 30
- n_generations: 20
- cxpb: 0.6 (blend crossover)
- mutpb: 0.3 (higher mutation for continuous space)
