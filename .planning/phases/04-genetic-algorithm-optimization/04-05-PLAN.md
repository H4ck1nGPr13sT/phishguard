  <name>Task 1: Create model registry module</name>
  <files>src/optimization/model_registry.py</files>
  <action>
Create model registry module for versioning and comparison:

**register_model(model_path, model_type, classifier_name, metrics, version_tag):**
- Log model to MLflow Model Registry
- Tag with version: "baseline" or "ga_optimized"
- Log metrics: accuracy, f1, precision, recall
- Include metadata: hyperparameters, training date, optimization method
- Return registered model version

**compare_versions(classifier_name, version_a, version_b, X_test, y_test):**
- Load both model versions
- Evaluate on same test set
- Calculate metrics: accuracy, f1, precision, recall, AUC-ROC
- Calculate improvement: (version_b - version_a) / version_a * 100
- Return comparison dict

**generate_comparison_report(classifiers, X_test, y_test):**
- For each of 7 classifiers:
  - Compare baseline vs ga_optimized
  - Calculate per-classifier improvement
- Add ensemble comparisons:
  - Equal-weight soft voting (baseline) vs weighted voting (optimized)
- Return structured report dict

**set_active_version(classifier_name, version_tag):**
- Update active model config (stored in cache/active_models.json)
- Log version change event
- Return confirmation

**get_active_model(classifier_name):**
- Read active version from config
- Load and return appropriate model
- Default to "ga_optimized" if available, else "baseline"

**Active model config format:**
```json
{
  "rf": {"version": "ga_optimized", "path": "models/optimized/rf_optimized.joblib"},
  "svm": {"version": "ga_optimized", "path": "models/optimized/svm_optimized.joblib"},
  ...
  "ensemble": {"version": "weighted", "path": "models/optimized/ensemble/weighted_voting.joblib"}
}
```

Update the FastAPI application to use the model registry for loading active models:

   Add import at top of file:
   ```python

   ```

2. **Update lifespan function:**
   Replace hardcoded model loading with registry-based loading:

   Instead of:
   ```python
   ml_models["phishing_detector"] = load_model(Path("models/rf_pipeline.joblib"))
   ```

   Use:
   ```python
   # Load active model from registry (defaults to GA-optimized if available)
   ml_models["phishing_detector"] = get_active_model("rf")
   ```

3. **Update ensemble loading:**
   Instead of loading specific ensemble files:
   ```python
   ml_models["voting_soft"] = load_ensemble(soft_path)
   ```

   Use:
   ```python
   # Load active ensemble from registry
   ml_models["ensemble"] = get_active_model("ensemble")
   ```

4. **Add fallback handling:**
   If registry is not configured (no cache/active_models.json), fall back to original behavior:
   ```python
   try:
       ml_models["phishing_detector"] = get_active_model("rf")
   except FileNotFoundError:
       # Fallback to baseline if registry not configured
       ml_models["phishing_detector"] = load_model(Path("models/rf_pipeline.joblib"))
   ```

5. **Update startup message:**
   Print which model version was loaded:
   ```python
   print(f"Primary model loaded: {model_version} version")
   ```

Keep backward compatibility - if active_models.json doesn't exist, the API should still work with baseline models.
