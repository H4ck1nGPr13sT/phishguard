<interfaces>
Endpoint response shapes app.js must normalize (from src/api/endpoints.py + models.py):
- POST /predict/multi-paradigm (JSON body {"url": "..."}) -> {final_prediction, final_probability, confidence, paradigm_contributions, disagreement, active_rules[{name,description,weight,matched_values}], explanation, processing_time_ms}
- POST /predict/email (JSON {"raw_email": "..."}) -> EmailSMSResponse {content_type, final_prediction, final_probability, confidence, feature_count, active_rules, explanation, ...}
- POST /predict/sms   (JSON {"message": "..."}) -> EmailSMSResponse (same shape, content_type="sms")
- POST /predict/email/file (multipart file=<.eml>) -> EmailSMSResponse (content_type="email")
- POST /predict/image (multipart file=<.png/.jpg/.jpeg>) -> EmailSMSResponse (content_type="image", visual_closest_brand?, visual_hash_distance?)
- Errors: 422 returns {"detail": [ {..obj..} ]} (array!); 400/503/500 return {"detail": "<string>"}. Render only strings.

normalize(d) contract (08-RESEARCH Pattern 2):
  probability = d.final_probability ?? d.phishing_probability ?? d.ensemble_probability
  prediction  = d.final_prediction ?? d.prediction ?? d.ensemble_prediction
  confidence  = d.confidence ?? d.ensemble_confidence
  explanation = d.explanation ?? ""
  rules       = d.active_rules ?? []
severityBand(p): p<0.25 "Low", p<0.5 "Medium", p<0.75 "High", else "Critical".

Template ids created in 08-02: #input-type (values url/email/sms), #input-text, #analyze-btn, #result, #upload-area, #batch-area.
CSP is `default-src 'self'` (Decision/08-02) — all JS must live in this external file; NO inline handlers. fetch() to same-origin relative paths with leading slash.
For multipart FormData fetch, do NOT set Content-Type manually (browser adds the boundary).
