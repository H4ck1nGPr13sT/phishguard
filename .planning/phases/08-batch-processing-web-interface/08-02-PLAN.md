Starlette/FastAPI (08-RESEARCH Pattern 1):
- Jinja2Templates request-first signature: `templates.TemplateResponse(request, "index.html", {...})` (old dict-first form is deprecated).
- StaticFiles at a nonexistent directory raises at import time — create src/web/static/ first.
- WEB_DIR = Path(__file__).resolve().parent.parent / "web"  (anchored at module, CWD-independent).

CSP caveat (NOT in research, load-bearing): FastAPI /docs (Swagger UI) and /redoc load assets and use inline scripts; a blanket `Content-Security-Policy: default-src 'self'` breaks them. The middleware MUST skip CSP for request paths in {/docs, /redoc, /openapi.json} while still applying nosniff + X-Frame-Options everywhere. Because index.html links external style.css/app.js (no inline <script>/<style>), default-src 'self' is satisfied for our pages.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → GET / and /static/* | Server delivers HTML/CSS/JS; response headers are the control surface |
| static mount → filesystem | StaticFiles serves only the src/web/static directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering (XSS) | HTML index + assets | mitigate | Jinja2 autoescape on for .html; external-only JS/CSS (no inline) so CSP `default-src 'self'` holds; CSP header added by middleware |
| T-08-02 | Tampering (clickjacking) | HTML index framed by attacker | mitigate | `X-Frame-Options: DENY` on all responses |
| T-08-03 | Spoofing (MIME sniffing) | static assets | mitigate | `X-Content-Type-Options: nosniff` on all responses |
| T-08-04 | Tampering (path traversal) | /static mount | mitigate | Starlette StaticFiles normalizes paths; only src/web/static exposed |
| T-08-05 | Availability regression | Swagger /docs broken by CSP | mitigate | CSP scoped to skip /docs,/redoc,/openapi.json; `test_docs_still_served` guards |
| T-08-SC | Tampering | jinja2 install | accept | Cleared in RESEARCH Package Legitimacy Audit ([OK]); already installed, lower-bound pin only |
