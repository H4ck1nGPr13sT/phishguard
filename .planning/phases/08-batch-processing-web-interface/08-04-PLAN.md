Create `src/api/batch.py`:
- Imports: csv, io, threading, uuid; FastAPI APIRouter/BackgroundTasks/File/HTTPException/UploadFile; the three inference helpers; the three Pydantic request models; pydantic ValidationError.
- Constants: MAX_CSV_BYTES = 1*1024*1024, MAX_CSV_ROWS = 500, MAX_CELL_CHARS = 5000, ALLOWED_TYPES = {"url","email","sms"}, MAX_JOBS = 50. Call `csv.field_size_limit(MAX_CELL_CHARS)` explicitly at module load (bound field size; do not leave the platform default).
- `JOBS: dict[str, dict] = {}` and `_LOCK = threading.Lock()`.
- `router = APIRouter()`.
- `_dispatch_row(row_type: str, content: str) -> dict` (THE monkeypatch seam — tests patch this string path): validate `row_type` in ALLOWED_TYPES and `len(content) <= MAX_CELL_CHARS`; instantiate the matching Pydantic request model to reuse validators (URLRequest/EmailTextRequest/SMSRequest) and raise on ValidationError; then route to predict_url_multi/predict_email_text/predict_sms_text and return {"prediction": r["final_prediction"], "probability": float(r["final_probability"])}.
- `run_batch(job_id: str, rows: list[dict])` (SYNC def — runs in threadpool, never async, per Anti-Patterns): set status "running"; for each row (1-indexed), build content_preview (first ~80 chars), call `_dispatch_row` inside try/except; on success append {row,type,content_preview,prediction,probability,error:None}; on ANY exception append a row with prediction="error", probability=0.0, and error = a SHORT generic message + exception class name (e.g. f"row failed: {type(e).__name__}") — NEVER str(e)/traceback (Info-disclosure control). Increment done under _LOCK after each row. One bad row must not abort the loop. Finally set status "done" (only set "failed" for an unexpected error OUTSIDE the per-row loop). Mutate job state only while holding _LOCK.
- `@router.post("/batch")` async def start_batch(background: BackgroundTasks, file: UploadFile = File(...)): reject non-.csv filename -> 400; `raw = await file.read(MAX_CSV_BYTES + 1)`; if len>MAX_CSV_BYTES -> 400 "File too large (max 1MB)"; decode utf-8-sig (400 on UnicodeDecodeError); csv.DictReader; require header contains {type,content} case-insensitively (400 otherwise); collect rows enforcing >MAX_CSV_ROWS -> 400; create job under _LOCK {status:"queued",total,done:0,rows:[]}; evict oldest beyond MAX_JOBS (pop first-inserted key); `background.add_task(run_batch, job_id, rows)`; return {"job_id": job_id, "total": len(rows)}. Process entirely in memory — NEVER write the upload to disk (V12).
- `@router.get("/batch/{job_id}")` def batch_status(job_id: str, offset: int = 0): look up JOBS; 404 if missing; under _LOCK return {"status","total","done","rows": job["rows"][max(offset,0):]} (return a slice/copy, not the live list).
In `src/api/main.py`: at the bottom (after ml_models + app, alongside the endpoints/web includes) add `from src.api.batch import router as batch_router` and `app.include_router(batch_router)`.

| Boundary | Description |

| client → POST /batch | Untrusted multipart CSV crosses into the API |
| CSV rows → inference helpers | Per-row untrusted content dispatched to models |
| job store → GET /batch/{id} | Job snapshots returned by unguessable id |

## STRIDE Threat Register (ASVS V5 Input Validation, V12 Files)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-10 | Denial of Service | oversized / zip-bomb-like CSV | mitigate | bounded `read(MAX+1)` 1MB cap BEFORE parse; 500-row cap; `csv.field_size_limit(5000)`; 5000-char/cell cap in _dispatch_row |
| T-08-11 | Tampering | disguised non-CSV upload | mitigate | `.csv` extension check + utf-8-sig decode + required type,content header |
| T-08-12 | Tampering | invalid per-row type/content | mitigate | `type` allowlist + reuse URLRequest/EmailTextRequest/SMSRequest validators per row (ValidationError -> row error) |
| T-08-13 | Info disclosure | stack trace / internal detail in row error | mitigate | store generic message + exception class name only; never str(e)/traceback |
| T-08-14 | Info disclosure | job-id enumeration | mitigate | uuid4.hex ids (122-bit); no list endpoint |
| T-08-15 | Denial of Service | job-store memory exhaustion | mitigate | MAX_JOBS eviction of oldest; per-job 500-row cap |
| T-08-16 | Tampering | upload persisted to disk / EXIF | mitigate | CSV processed in-memory (io.StringIO) only; never written to disk |
| T-08-17 | Denial of Service | event-loop block by CPU-bound inference | mitigate | run_batch is sync def (threadpool); lock held only for state mutation, not inference |
