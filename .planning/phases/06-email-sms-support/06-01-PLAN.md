<task type="auto">
  <name>Task 2: Create email_features.py module</name>
  <files>src/features/email_features.py</files>
  <action>
Create src/features/email_features.py following url_features.py pattern:

1. **parse_email(raw_email: bytes) -> dict** - Main parsing function
   - Use stdlib email.message_from_bytes with policy.default (RFC 5322 compliant)
   - Extract headers: From, To, Subject, Date, Reply-To, Authentication-Results
   - Extract body text (handle multipart/alternative - prefer text/plain, fall back to HTML)
   - For HTML bodies, use BeautifulSoup to extract plain text: soup.get_text(separator=' ', strip=True)
   - Return dict with 'headers', 'body', 'is_html', 'has_attachments'

2. **extract_email_header_features(msg: EmailMessage) -> Dict[str, float]** - Header features
   Features to extract (~15 features):
   - has_spf_pass: 1 if "spf=pass" in Authentication-Results, else 0
   - has_dkim_pass: 1 if "dkim=pass" in Authentication-Results, else 0
   - has_dmarc_pass: 1 if "dmarc=pass" in Authentication-Results, else 0
   - sender_domain_length: len(domain from From header)
   - reply_to_mismatch: 1 if Reply-To differs from From, else 0
   - has_multiple_recipients: 1 if multiple addresses in To header
   - subject_length: len(Subject header)
   - has_urgent_subject: 1 if "urgent", "important", "action required" in subject (case-insensitive)
   - has_re_prefix: 1 if subject starts with "Re:" or "RE:"
   - has_fwd_prefix: 1 if subject starts with "Fwd:" or "FW:"
   - header_count: total number of headers
   - has_x_headers: 1 if any X-* custom headers exist
   - from_domain_suspicious: 1 if sender domain in suspicious TLD list (tk, ml, ga, cf, gq, xyz)
   - has_received_headers: 1 if Received headers present (routing info)
   - received_header_count: count of Received headers

3. **extract_domain_from_email(email_address: str) -> str** - Helper
   - Extract domain from "Name <user@domain.com>" format
   - Handle edge cases: no angle brackets, multiple @, empty string
   - Use regex: r'@([\w.-]+)'

4. **_get_default_email_header_features() -> Dict[str, float]** - Defaults
   - Return all zeros for empty/invalid emails (follow url_features.py pattern)

Include comprehensive docstrings following Google style (Args, Returns, Examples).

IMPORTANT: Do NOT use dkimpy.verify() for actual DKIM signature validation (slow DNS lookup). Instead extract authentication status from Authentication-Results header which was already verified by the receiving mail server.
