Since we don't have a labeled email/SMS phishing dataset readily available, create a synthetic dataset for initial model training:

1. **Email samples** (100 phishing + 100 legitimate):
   - Phishing: Use templates with urgent subjects, suspicious domains, missing DKIM
   - Legitimate: Professional emails with proper headers, known domains

   **Variation requirements for quality:**
   - Domain diversity: At least 20 different sender domains (e.g., bank-security.tk, paypa1-verify.com, amazon-alerts.ru for phishing; gmail.com, company.com, university.edu for legitimate)
   - Urgency level distribution: 40% high urgency ("URGENT", "IMMEDIATE ACTION"), 30% medium, 30% low
   - Body length distribution: 20% short (<50 words), 50% medium (50-150 words), 30% long (>150 words)
   - Header completeness: Phishing 70% missing DKIM/SPF, legitimate 90% have complete headers
   - URL presence: 80% of phishing contain URLs, 30% of legitimate contain URLs

2. **SMS samples** (100 phishing + 100 legitimate):
   - Phishing: Use smishing templates (prize scams, account alerts, shortened URLs)
   - Legitimate: Order confirmations, appointment reminders, normal notifications

   **Variation requirements for quality:**
   - URL shortener diversity: At least 5 different shorteners (bit.ly, tinyurl.com, t.co, goo.gl, ow.ly)
   - Message length distribution: 30% very short (<20 chars), 50% medium (20-100 chars), 20% long (>100 chars)
   - Urgency level distribution: 50% high urgency for phishing, 10% for legitimate
   - Phone number presence: 20% of legitimate have callback numbers, 5% of phishing
   - Emoji usage: 10% of samples include emoji

3. **Quality validation before saving**:
   - Assert at least 15 unique phishing templates per type
   - Assert at least 15 unique legitimate templates per type
   - Assert domain diversity: len(set(domains)) >= 15 for each category
   - Assert no duplicate samples

def validate_dataset_quality(samples: List[dict], name: str):

    contents = [s["content"] for s in samples]

    # Check class balance

    assert abs(labels.count(0) - labels.count(1)) <= 10, f"{name}: class imbalance"

    print(f"{name}: {len(samples)} samples, {len(set(contents))} unique, balanced: {labels.count(0)}/{labels.count(1)}")

```python
def extract_all_features(samples, content_type: ContentType):
    features = []
    labels = []
    for sample in samples:
        if content_type == ContentType.EMAIL:
            feats = extract_email_features(sample["content"].encode())
        else:
            feats = extract_sms_features(sample["content"])
        features.append(list(feats.values()))
        labels.append(sample["label"])
    return np.array(features), np.array(labels)
```

def train_classifier(name, clf, X_train, y_train, X_test, y_test):
    pipeline = Pipeline([
        ("scaler", StandardScaler()),
        ("classifier", clf)
    ])
    pipeline.fit(X_train, y_train)
    accuracy = pipeline.score(X_test, y_test)
    print(f"{name}: {accuracy:.4f} accuracy")
    return pipeline, accuracy

def validate_models(output_dir):
    """Load and test each saved model to ensure it can predict."""
    for model_path in output_dir.glob("*.joblib"):
        model_data = joblib.load(model_path)
        model = model_data["model"]
        # Create dummy input with correct feature count
        dummy_features = np.zeros((1, model_data["feature_count"]))
        try:
            pred = model.predict(dummy_features)
            print(f"  {model_path.name}: predict OK (output: {pred})")
        except Exception as e:
            print(f"  {model_path.name}: FAILED - {e}")
