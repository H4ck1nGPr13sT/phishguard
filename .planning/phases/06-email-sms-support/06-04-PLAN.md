2. **Add ContentType enum**:
```python
class ContentType(Enum):
    URL = "url"
    EMAIL = "email"
    EMAIL_FILE = "email_file"  # .eml bytes
    SMS = "sms"
```

3. **Create module-level TextFeatureExtractor singleton** (load spaCy once):
```python
# Module-level extractor - loads spaCy model once
_text_extractor: Optional[TextFeatureExtractor] = None

def get_text_extractor() -> TextFeatureExtractor:
    """Get or create singleton TextFeatureExtractor."""
    global _text_extractor
    if _text_extractor is None:
        _text_extractor = TextFeatureExtractor()
    return _text_extractor
```

4. **Add extract_email_features(raw_email: bytes) -> Dict[str, float]**:
   - Parse email using parse_email()
   - Extract header features using extract_email_header_features()
   - Extract text features from body using TextFeatureExtractor
   - Prefix text features with "text_" to distinguish from header features
   - Return combined dict (~15 header + ~50 text = ~65 features)
   - Handle errors gracefully (return defaults on parse failure)

5. **Add extract_sms_features(message: str) -> Dict[str, float]**:
   - Extract SMS-specific features using extract_sms_specific_features()
   - Extract text features from message using TextFeatureExtractor
   - Prefix text features with "text_" to distinguish from SMS features
   - Return combined dict (~20 SMS + ~50 text = ~70 features)
   - Handle empty messages gracefully

6. **Add detect_content_type(content: Union[str, bytes]) -> ContentType**:
   - If bytes and starts with common email headers (From:, Subject:, MIME-Version:) -> EMAIL_FILE
   - If str and starts with http:// or https:// -> URL
   - If str and contains email header patterns (From:, Subject:) -> EMAIL
   - Otherwise -> SMS (default for plain text)

7. **Add extract_features(content: Union[str, bytes], content_type: Optional[ContentType] = None) -> Dict[str, float]**:
   - Main unified entry point
   - If content_type not provided, auto-detect with detect_content_type()
   - Route to appropriate extractor:
     - URL -> extract_url_features()
     - EMAIL -> parse as string email, extract_email_features()
     - EMAIL_FILE -> extract_email_features() with bytes
     - SMS -> extract_sms_features()
   - Add "content_type" feature (0=URL, 1=EMAIL, 2=SMS) for model awareness

Keep existing extract_url_features() and _get_default_features() unchanged.

Include comprehensive docstrings for all new functions.
