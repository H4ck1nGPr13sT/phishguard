```python
"""SMS/chat message feature extraction for phishing detection.

SMS phishing (smishing) has distinct patterns:
- Short messages (160 char limit per segment)
- Shortened URLs (bit.ly, tinyurl, etc.)
- Urgency language compressed into brief text
- Common shorthand and abbreviations
"""

import re
from typing import Dict

# Shortened URL domains commonly used in smishing
SHORTENED_URL_DOMAINS = {
    'bit.ly', 'tinyurl.com', 't.co', 'goo.gl', 'ow.ly',
    'is.gd', 'buff.ly', 'adf.ly', 'tiny.cc', 'tr.im',
    'short.to', 'cutt.ly', 'rebrand.ly', 'shorturl.at'
}
```

**parse_sms(message: str) -> dict** - Parse SMS message
- Returns dict with 'text', 'urls', 'phone_numbers', 'is_multipart'
- Extract URLs using regex: r'https?://[^\s]+'
- Extract phone numbers: r'\+?[\d\s-]{10,}'
- Detect multipart (>160 chars)
- Handle unicode/emoji (don't strip - they're features)

**extract_sms_features(message: str) -> Dict[str, float]** - SMS-specific features (~20 features)

Length features:
- sms_length: len(message)
- sms_segment_count: ceil(len(message) / 160) - SMS segments
- exceeds_single_sms: 1 if >160 chars
- char_per_word_avg: avg chars per word (short = abbreviations)

URL features:
- url_count: number of URLs in message
- has_shortened_url: 1 if any URL domain in SHORTENED_URL_DOMAINS
- shortened_url_count: count of shortened URLs
- url_to_text_ratio: url_length / message_length

Phone features:
- has_phone_number: 1 if phone pattern detected
- phone_number_count: count of phone patterns

Character features:
- has_emoji: 1 if emoji characters present
- emoji_count: count of emoji (regex: [\U0001F600-\U0001F64F] etc.)
- uppercase_word_count: words that are ALL CAPS
- exclamation_density: exclamation_count / word_count

SMS-specific patterns:
- has_call_to_action: 1 if "call", "text", "reply", "click" present
- has_urgency_caps: 1 if URGENT, IMPORTANT, ALERT in caps
- has_prize_claim: 1 if "won", "prize", "claim" pattern
- has_account_alert: 1 if "account", "suspended", "verify" pattern
- shorthand_ratio: count of common SMS abbreviations (u, ur, plz, etc.) / word_count
- numeric_string_count: count of number sequences (PIN, codes, amounts)

**_get_default_sms_features() -> Dict[str, float]** - All zeros for empty messages

Include comprehensive Google-style docstrings with examples.

NOTE: SMS features are designed to be combined with text_features.py NLP features in the unified extractor (Plan 04). Don't duplicate lexical/syntactic features here.
